# Desafio GitHub
## Objetivos
1. Criar sua conta no GitHub
2. Crie um repositorio
   - Crie um repositorio no GITHUB, nomeando-o como "desafio-github-markdown"
   - Adicione o seu REAME.md ao criar o repositorio
   - Utilize o GitHub.dev para editar seu projeto diretamente com o editor web do github.
   - lembre-se: o repositorio deve ser publico
3. Colaboração
   - Adicione um colaborador ao seu repositorio (pode ser um colega de curso ou voce mesmo em uma conta diferente) (nesse caso optei por ser eu mesmo em uma conta diferente)
   - Ambos devem fazer um clone do repositorio em suas maquinas locais.
   - Realizem alterações, Commits, abra issues e pull requests
4. Formatação em MarkDown
   - Edite o arquivo "README.md" em seu repositorio.
   - Utilize a linguagem markdown pra formatar as informaçoes sobre o desafio, instruções e uma breve descrição do seu projeto
